```
┌─────────────────────────────────────────────────┐

│    · 无法形成稳定的制度预期                        │
│    · 商业活动和产权保护无从谈起                    │
│    · 最优秀的人成为"孤独的异类"                    │
│  黄仁宇论断：这是"一切问题的症结"                  │
└─────────────────────────────────────────────────┘
```

## 六、全书"六大教训"知识固化卡

### 教训1：权力不等于能力（万历皇帝）

```
┌──────────────────────────────────────┐
│ 核心要义：即使最高权力，在没有制度     │
│ 支撑时也只是空壳                      │
│ 当代映射：CEO/创始人失去动力，公司     │
│ 陷入"无人驾驶"                       │
│ 行动指引：建立不依赖个人的决策机制     │
└──────────────────────────────────────┘
```

### 教训2：改革者必先自保（张居正）

```
┌──────────────────────────────────────┐
│ 核心要义：推动变革需要先建立不可撼动   │
│ 的制度基础，而非个人权威              │
│ 当代映射：推动变革的高管在权力更迭     │
│ 后被边缘化                           │
```
