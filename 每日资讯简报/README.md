# 每日资讯简报

前一日国内外时政、外交、金融、社会资讯 + 多方观点评析。

## 内容结构
1. **国内时政**：政策动向、重要会议、高层活动
2. **国际外交**：大国博弈、区域局势、多边外交
3. **宏观金融**：股市、汇率、大宗商品、央行政策
4. **社会重点**：民生政策、科技突破、公共事件

每条资讯均包含：事件概述 + 多角度分析 + 背后逻辑 + 普通人视角。

## 命名规范
- 每日文件：`YYYY-MM-DD.md`（日期为资讯对应的日期）
- 示例：`2026-07-29.md` 对应 7月29日的资讯汇总

## 生成机制
- 每日凌晨自动生成前一日的完整资讯简报
- 同步更新至「学习进度打卡总表」待学习清单

## 周度汇总
- 每周日生成当周重磅资讯思维导图复盘文档
- 保存至 `../每周思维导图汇总/` 目录

运行 `python3 sync_data.py` 即可在网页端查看。
