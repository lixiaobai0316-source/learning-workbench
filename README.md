# 📚 个人学习工作台

> 通史 · 近代史 · 资讯 · 口语 · 书籍 · 思维导图

## 访问地址

🌐 **[点击打开学习工作台](https://lixiaobai0316-source.github.io/learning-workbench/)**

## 功能

- 🏠 首页数据看板：今日更新、待学习、已完成、连续天数
- 📅 学习日历：点亮有更新的日期，点击查看内容
- 📰 各分类学习内容：通史/近代史/资讯/口语/书籍
- ✅ 学习进度追踪：标记已读/未读
- 📋 一键打卡模板
- 📊 周汇总与思维导图

## 手机添加到桌面

1. iPhone Safari 打开上面的链接
2. 点击分享按钮 → 添加到主屏幕
3. 桌面出现图标，一点就打开，全屏体验
